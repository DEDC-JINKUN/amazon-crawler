## ZIP参数

复用现有参数，不增加模式开关：

```toml
[context]
expected_country = "US"
expected_currency = "USD"
postal_code = ""
```

空值或省略postal_code表示美国站观察：保留ASIN身份、美国地区和美元证据检查；ZIP差异不触发Firefox，不单独导致partial。记录到的配送地区只说明当次页面，不代表全美统一价格。postal_confirmed为null表示不要求固定ZIP，不是假装已确认。

指定地区任务可显式设置postal_code="90001"，保留原有提交、刷新确认、失败partial和不提交未确认Cookie的约束。HTTP传输异常仍允许既有浏览器恢复，不再要求先配置ZIP。

**现有生产配置仍保留90001，未改动。** 以后发布本分支时，应在当前任务完成后明确将正式配置的postal_code清空；仅更新代码不会擅自重写旧配置。旧raw/evidence/partial记录保持原意。
